# Petrol Pump Management Website

This is a modern fullstack boilerplate for petrol pump management, featuring: configuration, operations, payroll, inspection, and reconciliation.

## Stack
- Frontend: React (TypeScript)
- Backend: Node.js (Express)
- Database: SQLite for simple demo, migrate to MySQL/PostgreSQL for production

## Folder Structure
```
/ (root)
|-- backend/
|    |-- server.js          # Express API server
|    |-- models/            # Data models
|    |-- routes/            # API endpoints
|    |-- db.js              # DB config
|-- frontend/
|    |-- src/
|        |-- App.tsx        # Main App
|        |-- components/    # React Components
|        |-- pages/         # Page components
|        |-- api.ts         # API calls
|-- README.md
```
